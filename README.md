
# Kalimantan Wildfire: Spatial and Economic Impact Analysis | Power BI

Developed an interactive Power BI dashboard to analyze the spatial distribution and environmental and socio-economic impacts of forest and land fires in Kalimantan. Performed data transformation using Power Query, developed analytical measures using DAX, and established data models to integrate multiple datasets. Designed Operations, Impact, and Executive dashboards to support data-driven insights and strategic decision-making.
